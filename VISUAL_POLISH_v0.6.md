# Nightfall Village v0.6 — Visual Polish / Vertical Slice

This update focuses on presentation quality while keeping the sample directly relevant to a large Ren'Py sandbox VN workflow.

## Added

- Fully interactive main menu (not a static mockup).
- Animated ambient petals.
- Original Nightfall branding.
- Stronger visual hierarchy and cyan/black UI language.
- Improved top HUD with money, time, stats and relationship bars.
- Polished bottom dialogue layout.
- Character portrait presentation for Aya.
- Improved map cards and objective context.
- Relationship screen with Love/Hatred visualization.
- Cleaner save/load screen.
- A short Aya vertical-slice scene that demonstrates persistent branching state.
- Existing F2 Developer Tools remain available.

## Why this helps the application sample

The vertical slice demonstrates the same kinds of development work expected in a large sandbox VN:

- conditional events;
- persistent relationship state;
- schedules and time;
- route gating;
- UI/UX;
- save-compatible variables;
- developer testing tools.

The project remains original: it does not reuse House of Shinobi source code, characters, dialogue, or game assets.
