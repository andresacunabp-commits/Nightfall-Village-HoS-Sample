# 60–90 Second Portfolio Video Script

Goal: show the reviewer the strongest systems immediately. Record at 1080p if possible. No voiceover is required; a short caption at the beginning is enough.

## 0:00–0:05 — Identity
Show the clean main menu for a few seconds.

Optional caption:
**Nightfall Village — Ren'Py/Python Shinobi Sandbox Portfolio Sample**

## 0:05–0:18 — Free household navigation
Start/continue a save in the protagonist home.
- Move the mouse across the bottom room icons.
- Let one room name appear on hover.
- Click Bedroom → Hallway → Living Room directly.
- Briefly hover one in-scene interactive object so its hotspot illumination/name is visible.

What this demonstrates: room-based sandbox navigation and low-noise interaction UX.

## 0:18–0:33 — Dynamic world map
Click MAP on the polished top HUD.
- Hover two circular destinations so their names appear.
- Make sure their location images are visible inside the circles.
- Travel to the Market or Village Square with one click.

What this demonstrates: manual world travel and custom map UI.

## 0:33–0:48 — Time / living world
Show a time-period change or an interaction that advances time.
- Re-open the map so the different Morning/Day/Evening/Night artwork is visible.
- If convenient, show a green availability marker changing with time.

What this demonstrates: simulation state connected to UI and location availability.

## 0:48–1:05 — Aya / branching event
Visit Aya House.
- Show the household location dock.
- Trigger or continue a short Aya event.
- Show one meaningful relationship choice and the polished dialogue UI.

What this demonstrates: persistent relationship state and conditional narrative content.

## 1:05–1:15 — Save/load
Open Save, save to a slot, return to Load, and show the saved slot screenshot.

What this demonstrates: complete playable vertical-slice workflow, not a mockup.

## 1:15–1:25 — Optional developer tooling
Only if the recording is still under 90 seconds and the screen is clean:
- Open developer tools in a development build.
- Show one event READY/BLOCKED explanation.

End caption:
**Original Ren'Py/Python implementation • AI-assisted prototype art • GitHub source + Windows build available**

## Recording rules

- Do not record any traceback, debug warning, cache rebuild, or broken/locked route unless intentional.
- Keep the mouse movement slow enough that hover states are readable.
- Prefer one continuous clean take over many flashy cuts.
- Stop at ~75 seconds if the core systems are already clear.
