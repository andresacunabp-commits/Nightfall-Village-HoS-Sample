# Nightfall Village — Shinobi Sandbox Systems Demo v0.3

Original Ren'Py/Python portfolio project designed to demonstrate the kind of systems needed by a large nonlinear sandbox visual novel.

## What this build demonstrates

- Original cinematic main menu and visual identity
- Bottom-anchored dialogue UI
- Visual world map
- Morning / Afternoon / Evening / Night cycle
- NPC schedules
- Love / Hatred relationship routes
- Strength and Reputation requirements
- Inventory and shop systems
- Night-only merchant
- Quest flags and event priorities
- Unlockable households and secret locations
- Multi-stage repeatable interactions
- "Living world" dialogue reactions
- Interactive spoiler-light guide
- Event discovery log
- Custom save/load/settings UI
- Developer progression controls
- Live Event Inspector that explains why events are blocked

## Portfolio positioning

This project does **not** copy House of Shinobi characters, art, dialogue, CGs, or story.
It is an original demonstration of similar *technical categories*: sandbox navigation,
time-sensitive events, relationship routes, progression gates, living-world reactions,
and developer tooling.

## Developer shortcut

Press **F2** while playing to open Developer Tools.

The Event Inspector is the most important technical feature in this build:
it evaluates the current save and shows whether every event is READY or BLOCKED,
including the unmet requirement.
