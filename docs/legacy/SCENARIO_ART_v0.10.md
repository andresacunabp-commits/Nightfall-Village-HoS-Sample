# Nightfall Village — Scenario Art Pass v0.10.1

This pass replaced flat prototype scenery with seven cinematic location backgrounds during an earlier development stage.

At that time the artwork was stored as validated base64 chunks in `game/assets/v10_parts/` and reconstructed at runtime. This document is retained as historical implementation context only; v0.15.0 uses the later native/master background pipeline.

Integrated locations in that milestone:
- Village Square
- Market Alley
- Training Ground
- Riverside
- Old Shrine / Shrine Path
- Aya Household exterior
- Aya Household hallway
