# Nightfall Village v0.6 — Visual Polish / Vertical Slice

Historical milestone notes.

v0.6 introduced the first polished presentation layer: an interactive main menu, ambient particles, Nightfall branding, top HUD, bottom dialogue UI, Aya portrait presentation, relationship UI, save/load polish, an Aya vertical slice, and developer tools.

The current v0.15.0 candidate has substantially replaced and extended this presentation. See the root README and changelog for current behavior.
