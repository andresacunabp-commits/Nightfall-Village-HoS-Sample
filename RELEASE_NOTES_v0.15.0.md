# Nightfall Village v0.15.0 — Portfolio Candidate

This release freezes the current portfolio feature set for review.

Highlights:
- persistent sandbox playthrough;
- room-by-room and world navigation;
- contextual icon dock with availability markers;
- hover-only direct scene interactions;
- dynamic four-period world map with circular image destinations;
- NPC schedules and time-sensitive content;
- Love / Hatred relationship routes;
- conditional event requirements and priorities;
- inventory, stats, quest flags, unlockable locations;
- custom menu/save/load/dialogue/HUD presentation;
- developer event inspection tools.

The project is an original Ren'Py/Python sample and contains no House of Shinobi proprietary source code, characters, dialogue, story content, or extracted assets.

Some environment and character presentation artwork is AI-assisted prototype art. The portfolio focus is programming, systems, UX integration, state management, debugging, and iterative development.
